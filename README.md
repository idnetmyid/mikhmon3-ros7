### First-Time Setup
1. Extract the downloaded package to your preferred folder.
2. **On the first launch, right-click `idnet.exe` and select "Run as administrator".**
3. Windows User Account Control (UAC) will ask for permission. Click **Yes** to allow the application to create the required symbolic link for the configuration file.
4. Once the setup is complete, the launcher can be closed and reopened normally without administrator privileges.

**Note:** Administrator privileges are required for the initial setup only. Subsequent launches do not normally require administrator privileges.

### Requirements & Notes
- Includes PHP 8.4.28 Portable.
- Requires the appropriate Microsoft .NET Desktop Runtime.
- Keep the `app`, `data`, and `php` folders in the same directory structure as the launcher.
